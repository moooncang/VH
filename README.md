# 베일하운 뒷골목 마사지숍

작가 문창놈의 작품 소개 사이트. 방마다 별도 HTML을 생성하는 정적 다중 페이지입니다. 원본 미니게임은 수정하지 않았습니다.

## 실행과 수정

Python 3.12 이상. 사이트 생성에는 표준 라이브러리만 필요합니다.

```sh
python3 _build/build.py
python3 -m http.server 8766
```

브라우저에서 `http://localhost:8766/`을 엽니다. HTML을 직접 수정하지 않습니다.

- `_build/data.py`: 작품 문구, 인물, 메뉴, 장소, 감정 코드 범위, 파일 경로, 링크 설정
- `_build/build.py`: 카르테·개업 페이지와 정적 사이트 빌드.
- `_build/immersive.py`: V2 공용 셸, 입구, 접수대, 대기실, 조향실, 시술실, 도시.
- `_build/core.js` + `_build/interactions.js`: JS 원본. 빌드 시 `assets/site.js`로 합칩니다.
- `assets/site.css`: V2 반응형 레이아웃, 숲빛 바탕, 크림색 종이, 공간 핫스폿, 커튼과 모달.
- `assets/site.js`: 생성 결과. 직접 수정하지 않습니다.
- `assets/art`: 새로 생성한 골목, 접수대, 조향실, 고지도 WebP 4장.
- `design`: Figma용 편집 가능 SVG 4종, 생성 스크립트와 작업 상태.
- `assets/guard.js`: 성인 확인 전 하위 페이지 진입 시 입구로 이동
- `assets/fonts`: 자체 호스팅 WOFF2 네 가족 및 각각의 라이선스
- `images/CS`: 인물 455장. 첫등장 5장 + 인물별 90장
- `images/B`: 배경 11장. WebP, 원본 비율 유지
- `tools/convert.py`: 작가 원본을 이름 그대로 WebP 변환
- `tools/qa.cjs`: Edge/Playwright PC·모바일 검수
- `qa/v2-report.json`: V2 실제 브라우저 검수 결과. PC 1440px, 모바일 390px 각 12페이지, 추가 320/768/1024px, 감정 그룹 50개.
- `qa/v2/`: V2 로컬 검수 스크린샷. Git 제외. `qa/report.json`은 V1 기록입니다.

## 그림 교체

인물 코드는 A 레이나 / B 네르 / C 세르피나 / D 이브레아 / E 카샤입니다.

| 파일 이름 | 의미 |
| --- | --- |
| `AP.webp` 등 | 첫등장, 대기실 큰 그림 |
| `A_0.webp` ~ `A_9.webp` | 평소, 명단 썸네일은 0번 |
| `A_10.webp` ~ `A_19.webp` | 기쁨 |
| `A_20.webp` ~ `A_29.webp` | 슬픔 |
| `A_30.webp` ~ `A_39.webp` | 당황 |
| `A_40.webp` ~ `A_49.webp` | 부끄러움 |
| `A_50.webp` ~ `A_59.webp` | 분노 |
| `A_60.webp` ~ `A_69.webp` | 유혹, 카르테 안에서만 사용 |
| `A_70.webp` ~ `A_79.webp` | 달아오름, 카르테 안에서만 사용 |
| `A_80.webp` ~ `A_89.webp` | 시술, 카르테 안에서만 사용 |

다른 인물도 앞 글자만 바꿉니다. `_build/data.py`의 `EXPRESSION_GROUPS`가 감정 탭과 변환기의 번호 범위를 함께 결정합니다. 탭을 열 때 실제 존재하는 파일 중 무작위 한 장을 선택합니다. 빠진 번호는 건너뛰고, 한 묶음이 통째로 없으면 이니셜 빈 액자를 표시합니다. 새 그림을 넣거나 제거한 뒤에는 다시 빌드하세요.

변환에는 Pillow가 필요합니다.

```sh
python3 -m pip install Pillow
python3 tools/convert.py "인물 별 컷씬 폴더 경로" --size 1600 --quality 76
python3 tools/convert.py "배경 폴더 경로" --backgrounds --output images/B --size 2048
python3 _build/build.py
```

인물 폴더의 바로 아래 파일 및 레이나·네르·세르피나·이브레아·카샤 하위 폴더만 읽습니다. H 폴더를 탐색하지 않습니다. 원본 PNG는 복사하지 않으며, 비율을 유지하고 확대하지 않습니다. 배경 대응은 data.py의 `ROOMS` 및 `PLACES`에서 변경합니다. 시술실 T/N은 시간대에 따라 전환됩니다.

## 아직 비어 있는 작가 입력

`_build/data.py`의 `CONFIG`에서 설정하고 빌드합니다.

- `MASA_URL`: 기존 레이나 인터랙티브 페이지 주소. 빈 값이면 준비 중, 입력하면 같은 탭 이동
- `CRACK_URL`: 크랙 작품 주소. 빈 값이면 작품 링크 준비 중
- `BGM`: 자체 호스팅 음원 경로. 빈 값이면 음악을 재생하지 않음. 효과음은 Web Audio 합성
- `RESERVATIONS`: `{'time':'...', 'name':'...', 'menu':'...'}` 목록. 요청서에 실제 예약이 없어 빈 장부로 표시
- `PROLOGUES`: `opening`과 `free` 본문. 현재 빈 값이며 출력 형식만 제공
- `COPY`: 유저노트·단축어 안내 문구. 미제공 내용은 빈 자리로 표시

향유 세 번째 병은 물음표만 표시합니다. 설정 내용은 사이트 데이터에도 포함하지 않았습니다. 시술실 인터랙션 전용 그림은 이번 원본 묶음에 없어 별도 미리보기를 넣지 않았습니다. 입구 장면은 제공된 모험가 거리 배경에 목재 문·비·등불을 조합했습니다.

## 조작

1~6 방 이동 / T 시간대 / M 효과음 / ESC 방 안내 / Enter 접수 벨 / 7 입구로 나가는 메뉴.

카르테: 감정 탭 선택, 같은 감정의 그림은 ← →, 인물은 Q/E. 터치에서는 미리보기와 이전·다음 버튼을 사용합니다. 도시: ↑ ↓ 장소 선택. 입력창과 메뉴가 열려 있을 때 전역 이동 단축키는 실행하지 않습니다.

시간대와 효과음은 localStorage에 기억합니다. 성인 확인은 세션에 기억하며, 브라우저 저장소가 차단되면 같은 탭의 window.name을 세션 대체로 사용합니다. 별도 창은 다시 확인합니다. 이 확인은 작품 안내를 위한 프런트엔드 장치이며 서버 인증은 아닙니다.

## 배포

GitHub 저장소 `VH`의 main 브랜치 루트를 Pages 소스로 설정합니다. 생성된 HTML, assets, images, `.nojekyll`을 함께 올립니다. 경로는 상대 주소여서 `/VH/` 하위 배포도 지원합니다. API 키, 외부 CDN, 백엔드가 필요하지 않습니다.

## 검수

```sh
npm install --no-save playwright
node tools/qa.cjs
```

기본 URL은 `http://127.0.0.1:8766/`입니다. `VH_URL` 환경 변수로 다른 주소를 지정할 수 있습니다. 검수는 설치된 Microsoft Edge를 headless로 사용합니다. 12페이지 × 1440/390px 전체 화면, 이미지·콘솔·가로 넘침, 시간대, 확인 화면, 키보드, 감정 탭, 저장소 차단 상황을 검사합니다.

모든 일러스트와 작품 데이터의 권리는 작가에게 있습니다. 폰트 라이선스는 `assets/fonts/*-OFL.txt`를 참조하세요.

## V2 인터랙션

접수대 표식으로 장부·메뉴·소문을 열고, 칸막이를 누르면 대사를 듣습니다. 대기실은 모두/직원/손님 필터와 이전·다음 인물 선택을 지원합니다. 그림 확대는 버튼·클릭, 감정 변형은 방향키·썸네일·터치 스와이프로 탐색합니다. 조향실은 향유 선택과 3장 노트, 달아오름 단계 표시를 제공합니다. 시술실 커튼은 열고 닫을 수 있고, 도시는 여섯 지도 핀과 장소 목록이 연동됩니다.

비·먼지 파티클, 마우스 시차, 페이지 전환, 효과음은 동작 감소 설정과 탭 비활성 상태를 존중합니다. 사용자 원본 이미지 파일은 수정하지 않았습니다.
